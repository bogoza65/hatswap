Export a backup

One file with every saved login and your settings, encrypted with your master password. Keep it somewhere safe: anyone with the file and the password has your accounts.

Hatswap first saves the live session of each active account whose site is open in a tab, so the backup is current.

Restore from a backup

Pick a Hatswap backup file and enter the password it was made with.

Hatswap is locked. Unlock it to add this backup to the accounts you already have.

Restoring never changes which account is active on a site. Open the Hatswap popup on the site and pick the account you want.
